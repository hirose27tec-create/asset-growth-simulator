# 作業ログ — 資産形成シミュレーター

記事執筆時の参考用に、実際に行った作業を時系列でまとめる。

## 2026-08-12

### 1. 要件定義（壁打ち）

- 1つ目のToDoアプリとテーマ・用途が異なるアイデアを検討。「資産形成シミュレーター」と「目標達成支援アプリ」の2案を比較し、実現時間（1〜2時間）とドメインの独立性から資産形成シミュレーターを採用。
- 1つ目のToDoアプリの技術スタック（Next.js + Tailwind CSS）と、つまずいた点（要件定義・スコープ管理）をヒアリング。
- MVPの機能範囲とスコープ外項目を明文化し、合意（→ [docs/requirements.md](requirements.md)）。
- 複利計算方式（年次複利）、デプロイ先（Vercel）を事前確定。

### 2. Plan Mode で実装プラン作成・承認

- 要件を反映した実装プランを作成し、ユーザーの承認を取得。

### 3. プロジェクトセットアップ

- `create-next-app` でTypeScript + Tailwind CSS + App Router構成を新規作成。
- 作業ディレクトリ名に日本語・スペースが含まれ、npmの命名制限（`asset-growth-simulator` のようなURL-friendly名が必要）に抵触したため、一時サブディレクトリ `asset-growth-simulator` に生成後、中身をルートへ移動する形で回避。
- `recharts` を追加インストール（グラフ描画用）。

### 4. 実装

- `lib/calculateGrowth.ts`：年次複利の計算ロジックを純粋関数として実装。
- `app/page.tsx`：入力フォーム・結果サマリーカード・年次推移グラフ（Rechartsの積み上げエリアチャート）を実装。
- `app/layout.tsx`：メタデータ（タイトル・説明）と `lang` 属性を日本語向けに変更。

### 5. 動作検証

- 計算ロジックを手計算相当のスクリプトで検算（例：初期100万円・月3万円・年利5%・20年 → 1年目 元本136万円/資産142.8万円 など、想定通りの値であることを確認）。
- `npm run build` を実行。RechartsのTooltip `formatter` の型不一致によるTypeScriptエラーが発生したため修正し、ビルド成功を確認。
- Playwright（`npx playwright`、Chromiumは既存インストール済みのものを利用）でNext.js開発サーバーに接続し、初期表示・入力変更後の再計算・グラフ再描画をスクリーンショットで確認。コンソールエラーがないことも確認。

### 6. デプロイ

- Vercel CLIがインストール済み・ログイン済み（アカウント: `hirose27tec-create`）であることを確認。
- デプロイ方法についてユーザーに確認したところ、進め方に関するフィードバック（各作業ごとに進捗・理由・次に達成できることを説明し、許可を得てから進める）を受け、一旦作業を停止してドキュメント整備を実施。
- 「GitHubリポジトリを作ってVercel連携」を選択。`git init`→初回コミット→`gh repo create --public --source=. --push`でリポジトリ作成・push。
- `vercel link`でVercelプロジェクトを作成後、`vercel git connect`でGitHubリポジトリとの連携を試みるも失敗（Vercel GitHub Appがそのリポジトリへのアクセスを許可されていなかったことが原因）。ユーザーにGitHub側の「Installed GitHub Apps」→Vercelの設定でリポジトリアクセスを追加してもらい、再実行して連携成功。
- `vercel --prod`で本番デプロイを実行し成功。本番URL: https://asset-growth-simulator-mu.vercel.app
- 以後`master`へのpushで自動再デプロイされる構成になった。

### 7. 追加要望：複数投資の統合管理（v2）

- デプロイ後、ユーザーから「一般的な投資とは別に、自分の実際の投資（カスタム）を追加し、複数の投資をまとめた資産を把握したい」との要望。参考資料として提示された`ICC_投資計算.md`は、誤って`.next/diagnostics`（Next.jsのビルドキャッシュ、ビルドのたびに消える場所）に保存されていたため、`docs/references/`へ移動。
- 資料には実在する投資会社名・具体的な金額や日付など個人の資産情報が含まれていたため、公開リポジトリへの誤コミットを防ぐ目的で`.gitignore`に個別追加（内容はローカルにのみ保持）。
- 内容を踏まえ、通貨（JPY/USD/GBP/EUR）・過去日付の開始日・ロールオーバー型投資の扱いなどを壁打ちで整理し、要件を確定（→ [docs/requirements.md](requirements.md) のv2追加要件を参照）。
- `lib/calculateGrowth.ts`を、年数カウント方式から「開始日〜終了日の経過年数（小数）を指数にとる複利計算」に書き換え。ICC資料に記載の実際の数値（例：£7,000・年利10%・28.41年→約£104,922）と計算結果を突き合わせて整合性を確認。
- `app/page.tsx`を単一フォームから「投資リスト」形式に全面刷新。投資の自由な追加・削除、通貨選択、為替レート編集、複数投資を色分けした積み上げグラフを実装。
- Playwrightで実際にICCの数値（3件の投資、GBP建て）を入力して動作確認。初回スクリーンショットではグラフの一部が縮んで見えたが、待機時間を延ばして再確認したところ、Rechartsのアニメーション途中を捉えていただけと判明（データ自体は各投資とも単調増加していることをNode上の計算でも確認済み）。
