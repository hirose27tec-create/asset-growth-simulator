# 作業ログ — 資産形成シミュレーター

記事執筆時の参考用に、実際に行った作業を時系列でまとめる。

## 2026-08-12

### 1. 要件定義（壁打ち）

- 1つ目のToDoアプリとテーマ・用途が異なるアイデアを検討。「資産形成シミュレーター」と「目標達成支援アプリ」の2案を比較し、実現時間（1〜2時間）とドメインの独立性から資産形成シミュレーターを採用。
- 1つ目のToDoアプリの技術スタック（Next.js + Tailwind CSS）と、つまずいた点（要件定義・スコープ管理）をヒアリング。
- MVPの機能範囲とスコープ外項目を明文化し、合意（→ [docs/requirements.md](requirements.md)）。
- 複利計算方式（年次複利）、デプロイ先（Vercel）を事前確定。

### 2. Plan Mode で実装プラン作成・承認

- 要件を反映した実装プランを作成し、ユーザーの承認を取得。

### 3. プロジェクトセットアップ

- `create-next-app` でTypeScript + Tailwind CSS + App Router構成を新規作成。
- 作業ディレクトリ名に日本語・スペースが含まれ、npmの命名制限（`asset-growth-simulator` のようなURL-friendly名が必要）に抵触したため、一時サブディレクトリ `asset-growth-simulator` に生成後、中身をルートへ移動する形で回避。
- `recharts` を追加インストール（グラフ描画用）。

### 4. 実装

- `lib/calculateGrowth.ts`：年次複利の計算ロジックを純粋関数として実装。
- `app/page.tsx`：入力フォーム・結果サマリーカード・年次推移グラフ（Rechartsの積み上げエリアチャート）を実装。
- `app/layout.tsx`：メタデータ（タイトル・説明）と `lang` 属性を日本語向けに変更。

### 5. 動作検証

- 計算ロジックを手計算相当のスクリプトで検算（例：初期100万円・月3万円・年利5%・20年 → 1年目 元本136万円/資産142.8万円 など、想定通りの値であることを確認）。
- `npm run build` を実行。RechartsのTooltip `formatter` の型不一致によるTypeScriptエラーが発生したため修正し、ビルド成功を確認。
- Playwright（`npx playwright`、Chromiumは既存インストール済みのものを利用）でNext.js開発サーバーに接続し、初期表示・入力変更後の再計算・グラフ再描画をスクリーンショットで確認。コンソールエラーがないことも確認。

### 6. デプロイ（保留中）

- Vercel CLIがインストール済み・ログイン済み（アカウント: `hirose27tec-create`）であることを確認。
- デプロイ方法（GitHub連携でVercel自動デプロイ／Vercel CLIで直接デプロイ／ユーザー自身で実施）についてユーザーに確認したところ、進め方に関するフィードバック（各作業ごとに進捗・理由・次に達成できることを説明し、許可を得てから進める）を受け、一旦作業を停止。ドキュメント整備を実施。
