# 要件定義書 — 資産形成シミュレーター

## 背景・目的

Section 1-0 課題2。1つ目の課題（ToDoリストWebアプリ、Next.js + Tailwind CSS）とはテーマ・用途の異なるオリジナルアプリをもう1つ開発・公開・記事化する。1つ目では「要件定義・スコープ管理」でつまずいたため、今回は実装前に機能範囲をユーザーとの壁打ちで確定し、開発中の要件揺れ・スコープ拡大を防ぐことを狙う。

## テーマ

**資産形成シミュレーター** — 投資条件を入力すると将来の資産推移を可視化するツール。認証やデータ永続化を持たない、フロントエンドのみで完結する計算・可視化アプリ。

1つ目のToDoアプリ（タスク管理）とはドメインが異なり、「似たコピー」にならないことを確認済み。

## 必須機能（MVP）

1. 入力フォーム：初期投資額 / 毎月積立額 / 想定年利率(%) / 積立年数
2. 複利計算ロジック：**年次複利**（各年末に「前年末残高＋その年の積立合計」に年利率を掛けて計算）
3. 結果サマリー：最終資産額 / 元本合計（初期投資＋積立総額） / 運用益（差額）
4. 年次推移グラフ：元本と運用益の積み上げ表示
5. Tailwindによるレスポンシブ対応
6. Vercelへのデプロイ

## スコープ外（今回は実装しない）

- ユーザー認証・DBへのデータ永続化
- 複数シナリオの保存・比較
- インフレ調整・税金・手数料計算
- 入力履歴の保存

## 技術スタック

- Next.js（App Router, TypeScript）— 1つ目と同じ
- Tailwind CSS v4 — 1つ目と同じ

## v2追加要件：複数投資の統合管理（2026-08-12）

初回デプロイ後、ユーザーから「複数の投資（通貨・開始日が異なる）をまとめて資産を把握したい」という追加要望があり、壁打ちの上で以下を追加実装した。

### 追加した機能

- 投資を**リスト形式で自由に追加・削除**できるようにした（件数上限なし）
- 投資ごとに以下を個別設定できるようにした：ラベル、**通貨（JPY/USD/GBP/EUR）**、元本（一括投資額）、毎月積立額（任意）、想定年利率、**開始日（過去日付も可）**、終了日（シミュレーション終了時点）
- **為替レート**（対円の概算値）をアプリ内に初期値として持たせ、画面上で編集可能にした
- 複数投資の合算グラフ（投資ごとに色分けした積み上げエリアチャート）と、今日時点の合計評価額・投下元本・運用益のサマリーを表示

### 計算方式の変更

当初の「年次複利ループ」（`years`を整数カウントする方式）から、**開始日・終了日から算出した経過年数（小数）を指数にとる複利計算式**に変更した。理由は、実在する投資商品（3年ごとにロールオーバーする定期性商品）の資産評価が、四半期や月単位ではなく経過年数の実数値ベースで計算されていたため、それに整合させる必要があったため。単純な複利として計算し、ロールオーバー特有のロジックは追加していない（同一利率が続く前提では数学的に連続複利と同じ結果になるため）。

### スコープ外のまま

- サーバー側でのデータ永続化（DB）：投資リスト・為替レートは引き続きブラウザのその場限りの状態のみ
- 為替レートの自動取得（外部APIなし、手動編集の概算値のみ）
- ロールオーバーごとの利率変動シミュレーション
