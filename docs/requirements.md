# 要件定義書 — 資産形成シミュレーター

## 背景・目的

Section 1-0 課題2。1つ目の課題（ToDoリストWebアプリ、Next.js + Tailwind CSS）とはテーマ・用途の異なるオリジナルアプリをもう1つ開発・公開・記事化する。1つ目では「要件定義・スコープ管理」でつまずいたため、今回は実装前に機能範囲をユーザーとの壁打ちで確定し、開発中の要件揺れ・スコープ拡大を防ぐことを狙う。

## テーマ

**資産形成シミュレーター** — 投資条件を入力すると将来の資産推移を可視化するツール。認証やデータ永続化を持たない、フロントエンドのみで完結する計算・可視化アプリ。

1つ目のToDoアプリ（タスク管理）とはドメインが異なり、「似たコピー」にならないことを確認済み。

## 必須機能（MVP）

1. 入力フォーム：初期投資額 / 毎月積立額 / 想定年利率(%) / 積立年数
2. 複利計算ロジック：**年次複利**（各年末に「前年末残高＋その年の積立合計」に年利率を掛けて計算）
3. 結果サマリー：最終資産額 / 元本合計（初期投資＋積立総額） / 運用益（差額）
4. 年次推移グラフ：元本と運用益の積み上げ表示
5. Tailwindによるレスポンシブ対応
6. Vercelへのデプロイ

## スコープ外（今回は実装しない）

- ユーザー認証・DBへのデータ永続化
- 複数シナリオの保存・比較
- インフレ調整・税金・手数料計算
- 入力履歴の保存

## 技術スタック

- Next.js（App Router, TypeScript）— 1つ目と同じ
- Tailwind CSS v4 — 1つ目と同じ
- Recharts（グラフ描画ライブラリ、今回新規採用）
